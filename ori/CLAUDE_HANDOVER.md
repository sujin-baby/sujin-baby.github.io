### 0) 명단방 전달 메시지 '마지막' 누락 버그 수정 (`ori/Main.js`)
- **요청 사항**: 단일 진행으로 마감된 의뢰(예: 10.30 밀크텐정 5명)의 경우 명단방 전달 메시지 하단에 '마지막'이 붙어야 하는데 붙지 않고 시트 링크와 방제만 생성된 문제 해결.
- **원인 분석**:
  - `listMsgText_`에서 의뢰 완료 여부를 판별할 때 `siblings_(runs, me)`를 호출하여 같은 명단 시트를 공유하는 진행 목록을 가져옴.
  - 기존 `siblings_`는 취소(종료)된 진행(`r['진행 상태'] === '종료'`)을 필터링하지 않아, 과거 2일차로 잡혀 있다가 취소 처리된 `#11.02 밀크텐정 2 (목표 0명, 종료)` 건이 `sib` 목록(2번째 요소)에 포함됨.
  - 이로 인해 `sib[sib.length - 1].row === me.row` 판정이 거짓(`Row 4 === Row 8` -> `false`)이 되어 마감 꼬리말(`tail`) 생성이 완전히 건너뛰어짐.
- **조치 사항**:
  - `siblings_`: 취소(종료) 상태이면서 실적이 없는(`!(Number(x['인원']) > 0)`) 진행은 sibling 목록에서 제외하도록 필터 보완.
  - `listMsgText_`: `me['총건수']`가 공란일 경우에도 `sib`의 목표인원 합으로 `total`을 자동 보완하도록 방어 로직 보강.
  - 구글 시트 '보낼메시지' 탭 12행 메시지 본문 하단에 `\n마지막`을 즉시 수동 반영 완료.

### 1) 배정 탭 및 한눈에 탭 '수령인(계정명) OR 닉네임' 매칭 지원 (`ori/Main.js`)
- **요청 사항**: 리뷰어가 폼 제출 시 카톡 닉네임 란에 본명이나 이니셜(예: 강효수 님이 `HS` 입력)을 적거나, 배정에 본명이 적혀 있을 때 '닉네임 확인'이나 '아직'으로 판정되는 불편 해소. "수령인이나 닉네임 둘 중 하나가 맞으면 체크하게 해줘" 요구 반영.
- **조치 사항**:
  - `rawInfo0_`: 폼 응답 시트 헤더에서 수령인/계정명(`MATCH.name`) 열 식별 추가 (`nameCol`, `name`).
  - `boughtFormula_`: 배정 탭 '산 수' 수식에 `nm`(수령인 열)을 추가 임포트하고, 카톡 닉네임 또는 수령인 중 하나라도 배정 닉네임(`$B`열)과 일치하면 구매로 인정하도록 수식 확장.
  - `checkFormula_`: 한눈에 탭의 '옵션 확인' 수식에 `L(2)`(이름/수령인 열)을 인자로 전달하여, 닉네임이나 이름 중 하나라도 배정 명단에 있으면 정상 매칭(`✔`)되도록 개선.
  - `notBought_`: 백엔드 미구매자 집계 시 카톡 닉네임뿐만 아니라 수령인 일치(`nmMatch`) 여부도 함께 판별하도록 동기화.
  - 실제 구글 시트 배정 탭(Row 58~70) 및 한눈에 탭(Row 44 J열)에 즉시 적용하여 강효수 님 건이 정상 완료(`✔`)로 변경됨을 검증 완료.

### 2) 체험단 가이드 생성기 GitHub Pages 웹앱 배포 (`guide/index.html`)
- **요청 사항**: 클로드 아티팩트로 사용하던 가이드 생성기를 수진 님의 GitHub(`sujin-baby.github.io/guide/`)에 독립 웹앱으로 배포하고, 모바일에서 상품 위치 찾기가 안 되던 문제 해결.
- **문제 원인 분석**:
  - 아이폰 사파리에서 쿠팡 상품 페이지를 열 때 모바일 쿠팡(`m.coupang.com`)으로 리다이렉트되며 주소창의 `#kw=...` 해시가 소실됨.
  - 북마크릿 실행 시 사파리 보안 정책상 `navigator.clipboard.readText()`가 차단되어 의뢰서 키워드를 읽지 못하고 상품명 추천 키워드(`sugKw`)로 자동 대체됨.
  - 모바일 쿠팡의 `/nm/search` 엔드포인트는 SSR/CSR 특성상 `DOMParser`가 상품 태그를 읽지 못해 `ids.length === 0`으로 즉시 차단(-1) 판정됨.
  - 설령 위치를 찾아도 생성기에서 의뢰서 키워드와 조회 키워드 불일치(`kwMismatch`)로 판정되어 위치 데이터를 삭제해 버림.
- **조치 사항**:
  - `guide/index.html`로 독립 PWA/웹앱 구축 (홈 화면 추가 지원).
  - 북마크릿(`bm-src`): 모바일 환경에서 키워드 소실 시 상품명 추천으로 임의 실행하지 않고, 사용자에게 의뢰서 키워드를 확인/입력받는 프롬프트 제공.
  - 쿠팡 검색 조회(`look`): `/np/search` 데스크톱 구조 요청 및 본문 정규식 매칭 폴백 추가로 모바일에서도 상품 위치 식별률 극대화.
  - 생성기(`main_js`): 키워드 불일치 시 위치 데이터를 강제 삭제하지 않고 정상 반영하도록 유연화.

## 3. 핵심 운영 수칙 (절대 준수)

1. **택배시트 및 개별 명단 시트 직접 수정 금지**: 수식이나 스크립트 참조가 깨질 수 있으므로 관리 시트('체험단 관리')를 통해서만 조작.

3. **가벼운 작업과 무거운 작업 분리**: 락 독점 사고를 방지하기 위해 명단방 텍스트 투입은 즉시 처리하되, 전체 시트 그리기는 지연 예약(`soonCheck_`) 활용.
