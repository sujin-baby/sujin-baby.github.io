의뢰서를 붙여넣으면 방제, 명단 제목, 공지, 상품 안내가 한 번에 만들어집니다.

의뢰서

예시 의뢰서

카톡에서 의뢰서 복사 → 아래 칸 클릭 → 붙여넣기. 붙여넣으면 바로 분석돼요.

상품 정보 가져오기

⚙️ PC 확장 프로그램 / 북마크 설치 안내 (필요할 때만)
(안 받아지면 여기)
  1. 확장 프로그램 받기 → 받은 product-locator.zip 압축 풀기 (윈도우: 오른쪽 클릭 → 압축 풀기 / 맥: 더블클릭). 푼 폴더는 지우지 말고 그대로 두세요.
  2. 크롬 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기.
  3. 압축해제된 확장 프로그램을 로드 → 방금 푼 product-locator 폴더 선택.
  4. 주소창 오른쪽 퍼즐 조각 아이콘 → 상품 위치 찾기 옆 핀을 눌러 고정. (단축키 Alt+Shift+F 도 돼요)
  5. 새 버전이 나오면 결과 상자에 알려 줘요: 다시 받아서 같은 폴더에 덮어쓰고 chrome://extensions에서 ↻(새로고침).
  1. PC 크롬: 코드 복사 → 북마크바 오른쪽 클릭 → 페이지 추가 → URL에 붙여넣기 (또는 아래 버튼을 북마크바로 끌기)
  2. 휴대폰: 코드 복사 (휴대폰) → 아무 페이지에서 북마크 추가·저장 → 북마크 목록 → 편집 → 그 북마크 → 주소 칸에 붙여넣기
